# Pink Messenger 2.1 — E2EE

Мессенджер с PostgreSQL, Socket.IO, HTTPS через Caddy и **сквозным шифрованием (E2EE)**.

## Что шифруется
- Текст сообщений: AES-256-GCM в браузере отправителя.
- Файлы: AES-256-GCM в браузере до загрузки на сервер.
- Ключ чата: случайный 256-битный AES-ключ. Сервер хранит только зашифрованные копии этого ключа.
- Ключ чата для каждого участника оборачивается его RSA-OAEP 3072-bit публичным ключом.

## Что видит сервер
Сервер видит аккаунты, участников чатов, время сообщений, размеры/имена файлов и зашифрованные данные. Открытый текст сообщений и содержимое файлов на сервер не отправляются.

## Важное ограничение
Приватный RSA-ключ пользователя хранится как зашифрованный AES-GCM контейнер, защищённый его паролем. Сам пароль сервер не получает. Если потерян пароль и этот зашифрованный ключ, восстановить старые E2EE-сообщения невозможно.

## Запуск
1. Установить Docker Desktop и Node.js 20+.
2. Скопировать `.env.example` в `.env` и задать `JWT_SECRET`.
3. Локально: `docker compose -f docker-compose.local.yml up -d`
4. `npm install`
5. `npm start`
6. Открыть `http://localhost:3000`.

## Production
Заполнить `.env` значениями домена и PostgreSQL, затем `docker compose up -d --build`. Caddy получает HTTPS-сертификат автоматически, если DNS домена указывает на сервер и открыты порты 80/443.
